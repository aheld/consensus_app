# Consensus

Universal group consensus & activity voting platform.

One organizer creates a voting session and shares a link. Friends tap it, type a name, and vote —
no app download, no account. MVP is restaurant picking; the engine underneath is activity-agnostic
(movies, travel, lodging, custom polls to follow).

**Primary goal:** time from "where should we eat?" to a booked table in under 5 minutes, versus
30+ minutes of group chat.

## Status

Pre-implementation. Product requirements are settled; the technical stack is under discussion.
No application code yet.
