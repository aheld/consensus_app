What the critics caught

Four harsh reviews, fresh context, blind compare

  • The share sheet shipped the mockup's placeholder text
    the words "app icon" rendered where a Messages glyph belongs — copied from the static frame and never replaced
    fixed
  • aria-pressed was broken on every chip in the app
    HEEx renders it empty when true and drops it when false, so a screen reader got no selection state — and a test was pinning the bug
    fixed
  • The paste-a-link caption claimed more than it pulled
    "photo + description pulled" over an empty description; the fetcher was right, the caption lied
    fixed
  • The splash button floated 130px above its mark
    now within 0.2% of the reference's position
    fixed
  • Deleting a user silently destroys every session they organized
    a real cascade nobody had written down; the confirmation now says so
    fixed
