# Build log

Frozen snapshots of the live progress boards that ran while a feature was being built.
Each file is a point-in-time record, not a document that gets maintained — if a claim in
one of them contradicts `docs/decisions.md`, `CLAUDE.md` or the code, **the snapshot is
the stale one** and should be read as history.

Nothing in here is authoritative. It exists so that "why does the app look like this, and
what was rejected along the way" has an answer six months from now.
